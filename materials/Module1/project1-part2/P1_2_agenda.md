# MA 213 Project 1 Week 2 Agenda

**Focus:** Evidence, slides, and feedback  
**Deliverable:** Project 1 Deliverable 2 checkpoint  
**Activity file:** `P1_2_activity.docx` (Google Docs template)

| Time | Activity |
|---|---|
| 0–5 min | Group check-in: confirm the project question, roles, and current blockers. |
| 5–15 min | Check the data source, observational unit, cleaning decisions, and missing or unusual values. |
| 15–30 min | Review numerical and categorical plots, tables, and interpretations. Improve at least one of each. |
| 30–40 min | Check reproducible R code and draft the presentation sequence. |
| 40–47 min | Exchange peer or instructor feedback and record one actionable revision. |
| 47–50 min | Complete the exit ticket, assign next steps, and confirm the Deliverable 2 work plan. |

**Bring to class:** Project 1 outline, data, R code, current plots or tables, and any presentation draft.
