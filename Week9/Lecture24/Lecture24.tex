\begin{frame}
\frametitle{Recall: CLT for the sample mean}

\formula{Central limit theorem (sample mean)}
{Sample means will be nearly normally distributed with mean equal to the population mean, $\mu$, and standard error equal to $\frac{\sigma}{\sqrt{n}}$.
\[ \bar{X} \sim N \pr{ mean = \mu, SE = \frac{\sigma}{\sqrt{n}} } \]
}

\begin{itemize}
    \item This is exactly true if the population distribution is Normal, regardless of sample size $n$ (we derived this in Lecture 16)
    % \pause
    \item But it is also true \emph{regardless of the shape of the population distribution}, as long as the sample size $n$ is sufficiently large.
    % \pause
    \item Different distributions will require different sample sizes for the CLT to ``kick in''.
    % \pause
    \item Rule of thumb is that $n \geq 30$ is sufficient for most distributions.
\end{itemize}

\end{frame}

\begin{frame}
\frametitle{Applying the CLT for the sample mean}
\dq{Assume that the conditions are met. If you know the population standard deviation $\sigma$, the sample size $n$, and the sample mean $\bar{X}$, how would you calculate a 95\% confidence interval for the population mean $\mu$?}

\soln{\only<2-3>{
\[point estimate \pm critical~value \times standard~error \]\\
\[\bar{X} \pm z^{\star} \times \frac{\sigma}{\sqrt{n}} \]
where $z^{\star}$ is the critical value from the standard Normal distribution for a 95\% confidence level (approximately 1.96).
}
}
\soln{\only<3>{
\[49 \pm 1.96 \times \frac{20}{\sqrt{10}} = 49 \pm 12.4= [36.6, 61.4]\]
}
}

\end{frame}

\begin{frame}
\frametitle{Applying the CLT for the sample mean}
\dq{Assume that the conditions are met. If you know the population standard deviation $\sigma$, the sample size $n$, and the sample mean $\bar{X}$, how would you design a hypothesis test at a significance level $\alpha$ to check whether the population mean is less than $\mu_0$?}

\soln{\only<2>{
$H_0: \mu = \mu_0$ \\
$H_A: \mu < \mu_0$ \\
Test statistic: \[ z_{obs} = \frac{\bar{X} - \mu_0}{\sigma / \sqrt{n}} \] \\
p-value: \[P(Z < z_{obs})\]\\
\texttt{pnorm(z\_obs)} \\
Check if p-value $< \alpha$ to make a conclusion.
}
}
\end{frame}

\begin{frame}
\frametitle{This Time}
What if the population is normal, but we don't know the population standard deviation, $\sigma$?

\begin{itemize}
    \item We can estimate $\sigma$ using the sample standard deviation $s$.
    \item However, this introduces additional uncertainty in our estimate of the standard error.
    \item If the sample size is large enough (Rule of thumb: $n \geq 30$), this additional uncertainty is negligible, because $s$ will be a good estimate of $\sigma$.
    \item But if the sample size is small, $s$ may not be a good estimate of $\sigma$.
    \item To account for this, we use a different distribution: the \hl{t-distribution}.
\end{itemize}

\end{frame}

\begin{frame}
\frametitle{Review: what purpose does a large sample serve?}

As long as observations are independent, and the population distribution is not extremely skewed, a large sample would ensure that...

\begin{itemize}

\item the sampling distribution of the mean is nearly normal

\item the estimate of the standard error, as $\frac{s}{\sqrt{n}}$, is reliable

\end{itemize}

\pause
For small samples, we need to be more careful about both of these points.

\begin{itemize}
\item We need to verify that the \hl{population distribution is approximately normal.}
\begin{itemize}
\item Look at the data, check for skewness/outliers
\item Think about the context
\end{itemize}
\item If we don't know $\sigma$, we need to address the uncertainty in $s$.
\begin{itemize}
\item \hl{$t$ distribution}
\end{itemize}
\end{itemize}

\end{frame}

We should exercise caution when verifying the normality condition for small samples. It is important to not only examine the data but also think about where the data come from.

\subsection{Introducing the \texorpdfstring{$t$}{t} distribution}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{frame}
\frametitle{The $t$ distribution}

\begin{itemize}

\item When the population standard deviation is unknown (almost always) and the population is Normal, the uncertainty of the standard error estimate is addressed by using a new distribution: the \hl{$t$ distribution}.

\pause

\item This distribution also has a bell shape, but its tails are \hl{thicker} than the normal model's.

\pause

\item Therefore observations are more likely to fall beyond two SDs from the mean than under the normal distribution.

\pause

\item Extra thick tails are helpful for resolving our problem with a less reliable estimate the standard error (since $n$ is small)

\end{itemize}

\begin{center}
\includegraphics[width=0.5\textwidth]{\chp7@path/7-1_one_t/figures/tDistCompareToNormalDist/tDistCompareToNormalDist}
\end{center}

\end{frame}

\begin{frame}
\frametitle{The $t$ distribution (cont.)}

\begin{itemize}

\item Always centered at zero, like the standard normal ($z$) distribution.

\item Has a single parameter: \hl{degrees of freedom} (\mathhl{df}).

\end{itemize}

\frametitle{Back to Guinness: Sample Statistics}

\begin{itemize}

\item Sample standard deviation ($s$): 0.17
\item Sample size ($n$): 8

\orange{n = 8}
\end{align*}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%


\begin{frame}
\frametitle{Finding the test statistic}

\formula{Test statistic for inference on a small sample mean}
{The test statistic for inference on a small sample ($n < 30$) mean is the $t$ statistic with $df = n - 1$.
\[ t_{obs} = \frac{\text{point estimate} - \text{null value}}{SE} \]}

\pause

\vspace{-0.5cm}

\hl{in context...}
\begin{eqnarray*}
point~estimate &=& \bar{x} = 4.66 \\
\pause
SE &=& \frac{s}{\sqrt{n}} = \frac{0.17}{\sqrt{8}} = 0.060 \\
\pause
t_{obs} &=& \frac{4.66 - 4.5}{0.060} = 2.73 \\
\pause
df &=& 8 - 1 = 7
\end{eqnarray*}

\vspace{-0.25cm}

\Note{Null value is 4.5 because in the null hypothesis we set $\mu = 4.5$.}

\end{frame}

\begin{frame}[fragile]
\frametitle{Finding the p-value}

\begin{itemize}
\item The p-value is calculated as the tail area under the $t$ distribution.
\pause
\item Using R:

> 2 * pt(2.73, df = 7, lower.tail = FALSE)

\end{verbatim}
