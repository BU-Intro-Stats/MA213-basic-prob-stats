### Project2-3: Project 2 report prep


# Lesson Plan (50 mins)
- 5 mins: Go over P2_3_activity.pdf, the Deliverable 3 requirements (P2_D3_Report template), and P2_Rubric.pdf
- 20 mins: Groups work on steps 1-2; instructors rotate through groups for the Deliverable 2 and R code check-in (~5 min per group) and initial both boxes on each group member's sheet
  - Deliverable 2 hasn't been graded yet, so the check-in is the group's feedback: go over both analyses (table and plot match the research question and are labeled; test fits the variable types; hypotheses are about the population parameter, in words and symbols; each condition is checked with actual numbers; test statistic, df, and p-value are correct; conclusion is in context) and make sure students write down every change
  - R code check: runs top to bottom in a clean environment, reads the submitted data file, is commented, produces every table/figure/statistic, and doesn't use built-in test functions
- 15 mins: Pair up groups for step 3 (~6 min of presenting per group, one section per group member); keep doing check-ins with groups that haven't had one
- 10 mins: Groups work on Deliverable 3 (step 4); finish any remaining check-ins, prioritizing groups that haven't had one
- Collect worksheets at the end of lab
