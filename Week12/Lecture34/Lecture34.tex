\section{Recap: Inference for the slope in simple linear regression}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{frame}
  \frametitle{We want to perform inference for the regression slope}

Now, for regression, we will assume that the \textbf{residuals} are iid normal:
\[y_i = \beta_0 + \beta_1 x_i + \epsilon_i \quad \text{ where } \epsilon_i \overset{\mathrm{iid}}{\sim} N(0, \sigma) \qquad i=1,2,\ldots,n \]

(This is why we checked the conditions on the residuals earlier!)

\pause

  If this model is correct, then we have a sampling distribution for the estimated slope, $b_1$:
  \[ \frac{b_1-\beta_1}{SE_{b_1}} \sim t_{df} \qquad df=n-2\]
  \pause

  So now if I give you $b_1$, $SE_{b_1}$, and $n$, you already have all of the tools do a hypothesis test or to build a confidence interval for $\beta_1$!
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{frame}
\frametitle{Testing for the slope}

{\footnotesize
\begin{center}
\begin{tabular}{rrrrr}
  \hline
 & Estimate & Std. Error & t value & Pr($>$$|$t$|$) \\ 
  \hline
(Intercept) & 9.2076 & 9.2999 & 0.99 & 0.3316 \\ 
  bioIQ & 0.9014 & 0.0963 & 9.36 & 0.0000 \\ 
   \hline
\end{tabular}
\end{center}
}

% \pause

\begin{itemize}

\item We always use a $t$-test in inference for regression. $\:$ \\

% \pause

\Remember{Test statistic, $T = \frac{point~estimate - null~value}{SE}$}

% \pause

\item Point estimate = $b_1$ is the observed slope.

% \pause

\item $SE_{b_1}$ is the standard error associated with the slope.

% \pause

\item Degrees of freedom associated with the slope is $df = n - 2$, where $n$ is the sample size. $\:$ \\
% \pause
\Remember{Just like in the ANOVA, we lose 1 degree of freedom for each parameter we estimate, and in simple linear regression we estimate 2 parameters, $\beta_0$ and $\beta_1$.}

\end{itemize}

\end{frame}

\begin{frame}
\frametitle{Recap}

\begin{itemize}

\item Inference for the slope for a single-predictor linear regression model:
\pause
\begin{itemize}
\item Hypothesis test:
\[ T = \frac{b_1 - null~value}{SE_{b_1}} \qquad df = n - 2 \]
\pause
\item Confidence interval:
\[ b_1 \pm t^\star_{df = n - 2} SE_{b_1} \]
\end{itemize}

\pause

\item The null value is often 0 since we are usually checking for \hl{any} relationship between the explanatory and the response variable.

\pause

\item The regression output gives $b_1$, $SE_{b_1}$, and \hl{two-tailed} p-value for the $t$-test for the slope where the null value is 0.

\pause

\item We rarely do inference on the intercept, so we'll be focusing on the estimates and inference for the slope.

\end{itemize}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%


\begin{frame}
\frametitle{Caution}

\begin{itemize}

\item Always be aware of the type of data you're working with: random sample, non-random sample, or population.

\pause

\item Statistical inference, and the resulting p-values, are poorly defined when you already have population data.

\pause

\item If you have a sample that is non-random (biased), inference on the results will be unreliable.

\pause

\item The ultimate goal is to have independent observations.

\end{itemize}

\end{frame}

\begin{frame}
\frametitle{How to include categorical variables in regression models}

\begin{itemize}
\item Categorical variables can be included in regression models using \hl{indicator} (dummy) variables, that each take on values 0 or 1.
\item For a categorical variable with $k$ levels, we include $k-1$ indicator variables.
\item One level is chosen as the \hl{reference level}, and the coefficients of the indicator variables represent the difference from this reference.
\end{itemize}

\end{frame}
