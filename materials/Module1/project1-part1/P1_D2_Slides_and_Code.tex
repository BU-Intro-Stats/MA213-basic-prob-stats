\begin{center}
\textbf{\Large Deliverable 2 \\ Slides and R Code}
\end{center}

Your group will submit draft \textbf{slides} for your video presentation and the \textbf{R code} used to generate the visualizations and analyses.
The slides should include the following sections and be limited to fewer than 7 slides total (not counting references and responsibilities slides):

\begin{enumerate}
    \item Title Slide (Project title, group members, date)
    \item Data Source and Description
    \item Numerical Data Analysis and Visualization
    \item Categorical Data Analysis and Visualization
    \item Conclusion and Future Work
    \item References (if applicable)
    \item Roles and Responsibilities of Each Group Member
\end{enumerate}

\vspace{6pt}
\noindent \textbf{Data Description Requirements:}
\begin{itemize}
    \item Provide a brief description of the numerical variables.
    \item Provide a brief description of the categorical variables.
    \item Indicate whether there is any missing data.
    \item Indicate whether there are any outliers.
\end{itemize}

\vspace{6pt}
\noindent \textbf{Numerical Data Section – Please include:}
\begin{itemize}
    \item At least one histogram.
    \item At least one boxplot.
    \item At least one scatter plot.
    \item At least one summary statistics table.
\end{itemize}

\vspace{6pt}
\noindent \textbf{Categorical Data Section – Please include:}
\begin{itemize}
    \item At least one bar plot.
    \item At least one summary statistics table such as frequency table or contingency table.
\end{itemize}

\vspace{6pt}
\noindent \textbf{R Code Submission:}
\begin{itemize}
    \item Submit the \textbf{R code} used to perform your numerical and categorical data analyses and generate visualizations as a \texttt{.R} or \texttt{.Rmd} file.
    \item The code should be well-commented to explain the steps taken in the analysis.
    \item Ensure that the code can be run without errors, assuming the data file is in the same directory.
    \item You should only use functions and packages that have been covered in class, tutorials, or labs, or are part of the standard R distribution.
    \item The group will be asked to explain the code during the lab session for Project 1-2, so make sure each member understands the code and can discuss it.
\end{itemize}
