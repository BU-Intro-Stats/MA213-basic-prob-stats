\begin{center}
\textbf{\Large Deliverable 2 \\ Presentation Plan} 
\end{center}

Your group will submit \textbf{draft slides} (please provide one printed copy per group) for your video presentation and the \textbf{R code} as part of the presentation plan.
The draft slides should include the following sections and be limited to fewer than 7 slides total (excluding references and responsibilities slides):

\begin{enumerate}
    \item Title Slide (Project title, group members, date)
    \item Data Source and Description
    \item Numerical Data Analysis and Visualization
    \item Categorical Data Analysis and Visualization
    \item Conclusion and Future Work
    \item References (if applicable)
    \item Roles and Responsibilities of Each Group Member
\end{enumerate}

In addition to the draft slides, please also submit:

\begin{itemize}
    \item The \textbf{R code} used to perform your numerical and categorical data analyses and generate visualizations (You can submit this file through email. Please list the name of your group and group memebers in the email).
    \item A summary of roles and responsibilities for each group member.
\end{itemize}

\vspace{6pt}
\noindent \textbf{Data Description Requirements:}
\begin{itemize}
    \item Provide a brief description of the numerical variables.
    \item Provide a brief description of the categorical variables.
    \item Indicate whether there is any missing data.
    \item Indicate whether there are any outliers.
\end{itemize}

\vspace{6pt}
\noindent \textbf{Numerical Data Section – Please include:}
\begin{itemize}
    \item At least one histogram.
    \item At least one boxplot.
    \item At least one scatter plot (if applicable).
    \item At least one summary statistics table.
\end{itemize}

\vspace{6pt}
\noindent \textbf{Categorical Data Section – Please include:}
\begin{itemize}
    \item At least one bar plot.
    \item At least one pie chart.
    \item At least one summary statistics table such as frequency table or contingency table.
\end{itemize}
