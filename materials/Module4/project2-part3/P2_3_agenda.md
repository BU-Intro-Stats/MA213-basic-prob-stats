# MA 213 Project 2 Week 3 Agenda

**Focus:** Progress report and final revision planning  
**Deliverable:** Project 2 Deliverable 3 checkpoint  
**Activity file:** `P2_3_activity.docx` (Google Docs template)

| Time | Activity |
|---|---|
| 0–5 min | Group check-in: identify the strongest part of the project and the largest remaining blocker. |
| 5–15 min | Review the introduction, data description, research questions, and citations. |
| 15–27 min | Check categorical and numerical analyses, conditions, computations, and contextual conclusions. |
| 27–35 min | Review tables, figures, writing flow, and the connection between evidence and claims. |
| 35–43 min | Test R code and data-file reproducibility; remove unused or scratch work. |
| 43–47 min | Exchange peer or instructor feedback and choose final revisions. |
| 47–50 min | Assign owners and deadlines for final writeup, R code, data, and proofreading. |

**Bring to class:** Draft writeup, R code, data file, tables or figures, and the Project 2 Deliverable 2 materials.
