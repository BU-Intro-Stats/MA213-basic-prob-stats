### Lab 1: Lab orientation, R setup, and Tutorial 1

**Lecture anchor:** Lecture 1  
**Purpose:** Get you set up and show you how lab works for the rest of the semester. There is no new statistics in this lab.

**Primary objectives supported**
- Use R for Data Management and Exploration
- Carry out a reproducible statistical workflow in R

**Pre-lab activity**
- Bring a laptop
- Review the Lab 1 materials before your lab session

**In-lab activity**
- Lab orientation: how lab runs, the weekly rhythm, grading, projects, and ground rules
- Install R and RStudio, and confirm they open without errors
- Complete Tutorial 1 and submit your hash code to Blackboard
- Import a data set with `read.csv()` and compute a simple column summary
- Work through the worksheet with a partner and hand it in

**Post-lab activity**
- Lab1 in-lab activity submission

**Deliverables**
- Tutorial 1 hash code submitted to Blackboard

**Notes**
- Install **R first, then RStudio**. RStudio is only a front end and will not run without R.
- Your hash code goes to **Blackboard**. Writing it on the worksheet does not count as submitting it.
- One submission covers both the hash code and the worksheet for that lab.
