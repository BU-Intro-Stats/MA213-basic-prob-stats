# MA 213 Project 2 Week 1 Agenda

**Focus:** Project launch and analysis planning  
**Deliverable:** Project 2 Deliverable 1 outline  
**Activity file:** `P2_1_activity.docx` (Google Docs template)

| Time | Activity |
|---|---|
| 0–5 min | Form groups, confirm roles, and choose a project topic. |
| 5–15 min | Identify a credible data source, observational unit, and key variables. |
| 15–25 min | Write one categorical and one numerical research question. |
| 25–35 min | Select preliminary inference methods and identify the conditions to check. |
| 35–43 min | Review data quality, feasibility, and planned plots or tables. |
| 43–48 min | Assign responsibilities and set a timeline for Deliverable 2. |
| 48–50 min | Complete the submission checklist and record any instructor question. |

**Bring to class:** A possible topic, candidate dataset, and ideas for both categorical and numerical analyses.
