\textbf{Big idea:} Two dolphins, Doris and Buzz, were trained to push buttons in response to a signal light. In the final phase, a curtain was placed between them so that only Doris could see the light. We will decide, individually and then with a partner, whether Buzz's performance is evidence that the dolphins communicated.

\section*{The Case Study}

A curtain is placed between the dolphins. Only Doris can see the headlight; Buzz cannot. Doris must ``tell'' Buzz which button to push, using only sounds. In one phase of the study, Buzz was given 16 trials to push the correct button, and he chose correctly \textbf{15 out of 16 times}.

\[ \text{Proportion correct: } \frac{15}{16} = 0.9375 \; (93.75\%) \]

\textbf{Is this evidence that Doris and Buzz could communicate?}

\section*{Step 1: Think (2 mins)}

On your own, consider:
\begin{itemize}
  \item Based on these data, do you think Buzz somehow knew which button to push?
  \item What are the two possible explanations for Buzz pushing the correct button most of the time?
\end{itemize}
