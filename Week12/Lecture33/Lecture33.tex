\begin{frame}
\frametitle{The least squares line}

\[ \mathhl{ \hat{y} = \beta_0 + \beta_1 x } \]

\begin{itemize}
\item $\hat{y}$: Predicted value of the response variable, $y$
\item $\beta_0$: Intercept, parameter
\begin{itemize}
\item $b_0$: Intercept, point estimate (sometimes called $\hat{\beta}_0$)
\end{itemize}
\item $\beta_1$: Slope, parameter
\begin{itemize}
\item $b_1$: Slope, point estimate (sometimes called $\hat{\beta}_1$)
\end{itemize}
\item $x$: Explanatory variable
\end{itemize}

\end{frame}

\section{Edfinity Quiz: Which parts are random?}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{frame}
\frametitle{Reminder: Using probability models for inference}

Remember: The difference between descriptive statistics and inference is that in inference, we make statements about a \textbf{population} based on a \textbf{sample}.
\pause

We use a probability model for the sample to understand the randomness in our sample statistic (the \textbf{sampling distribution} of the statistic).

\pause
For example, when working with continuous data, we have often assumed that the data are independent, identically distributed (iid) normal:
\[X_i\overset{\mathrm{iid}}{\sim} N(\mu, \sigma) \qquad i=1,2,\ldots,n \]

\end{frame}


%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{frame}
    \frametitle{Reminder: using a sampling distribution for inference}
    Using the iid normal model, we know that the sampling distribution of the sample mean is (unknown $\sigma$):

    \[ \frac{\bar{X}-\mu}{SE_{\bar{X}}} \sim t_{df} \qquad \text{where} \quad df = n-1 \quad \text{and} \quad SE_{\bar{X}} = \frac{s}{\sqrt{n}} \]
  \pause

    Then we can do a hypothesis test:
    \begin{itemize}
      \item $H_0: \mu = \mu_0$ and $H_A: \mu \ne \mu_0$
      \item $T=\frac{\bar{X} - \mu_0}{SE_{\bar{X}}}$
      \item $p$-value: \texttt{2*(1-pt(abs(T), df))}
      \item Inference: Reject or fail to reject $H_0$
    \end{itemize}
    \pause

    And we can construct a confidence interval:
    \[ \bar{X} \pm t^\star_{df} \times SE_{\bar{X}} \]
\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{frame}
  \frametitle{We want to perform inference for the regression slope}

Now, for regression, we will assume that the \textbf{residuals} are iid normal:
\[y_i = \beta_0 + \beta_1 x_i + \epsilon_i \quad \text{ where } \epsilon_i \overset{\mathrm{iid}}{\sim} N(0, \sigma) \qquad i=1,2,\ldots,n \]

(This is why we checked the conditions on the residuals earlier!)

\pause

  If this model is correct, then we have a sampling distribution for the estimated slope, $b_1$:
  \[ \frac{b_1-\beta_1}{SE_{b_1}} \sim t_{df} \qquad df=n-2\]
  \pause

  So now if I give you $b_1$, $SE_{b_1}$, and $n$, you already have all of the tools do a hypothesis test or to build a confidence interval for $\beta_1$!
\end{frame}

\begin{frame}
\frametitle{Testing for the slope}

\pq{Assuming that these 27 twins comprise a representative sample of all twins separated at birth, we would like to test if these data provide convincing evidence that the IQ of the biological twin is a significant predictor of IQ of the foster twin. What are the appropriate hypotheses?}

\begin{enumerate}[(a)]
\item \mathhl{H_0:} $b_0 = 0$; \mathhl{H_A:} $b_0 \ne 0$ 
\item \mathhl{H_0:} $\beta_0 = 0$; \mathhl{H_A:} $\beta_0 \ne 0$ 
\item \mathhl{H_0:} $b_1 = 0$; \mathhl{H_A:} $b_1 \ne 0$ 
\solnMult{ \mathhl{H_0:} $\beta_1 = 0$; \mathhl{H_A:} $\beta_1 \ne 0$ }
\end{enumerate}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{frame}
\frametitle{Testing for the slope (cont.)}

{\footnotesize
\begin{center}
\begin{tabular}{rrrrr}
  \hline
 & Estimate & Std. Error & t value & Pr($>$$|$t$|$) \\ 
  \hline
(Intercept) & 9.2076 & 9.2999 & 0.99 & 0.3316 \\ 
  bioIQ & 0.9014 & 0.0963 & 9.36 & 0.0000 \\ 
   \hline
\end{tabular}
\end{center}
}

\pause

\begin{itemize}

\item We always use a $t$-test in inference for regression. $\:$ \\

\pause

\Remember{Test statistic, $T = \frac{point~estimate - null~value}{SE}$}

\pause

\item Point estimate = $b_1$ is the observed slope.

\pause

\item $SE_{b_1}$ is the standard error associated with the slope.

\pause

\item Degrees of freedom associated with the slope is $df = n - 2$, where $n$ is the sample size. $\:$ \\
\pause
\Remember{Just like in the ANOVA, we lose 1 degree of freedom for each parameter we estimate, and in simple linear regression we estimate 2 parameters, $\beta_0$ and $\beta_1$.}

\end{itemize}

\end{frame}

\begin{frame}
\frametitle{Recap}

\begin{itemize}

\item Inference for the slope for a single-predictor linear regression model:
\pause
\begin{itemize}
\item Hypothesis test:
\[ T = \frac{b_1 - null~value}{SE_{b_1}} \qquad df = n - 2 \]
\pause
\item Confidence interval:
\[ b_1 \pm t^\star_{df = n - 2} SE_{b_1} \]
\end{itemize}

\pause

\item The null value is often 0 since we are usually checking for \hl{any} relationship between the explanatory and the response variable.

\pause

\item The regression output gives $b_1$, $SE_{b_1}$, and \hl{two-tailed} p-value for the $t$-test for the slope where the null value is 0.

\pause

\item We rarely do inference on the intercept, so we'll be focusing on the estimates and inference for the slope.

\end{itemize}

\end{frame}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%


\begin{frame}
\frametitle{Caution}

\begin{itemize}

\item Always be aware of the type of data you're working with: random sample, non-random sample, or population.

\pause

\item Statistical inference, and the resulting p-values, are meaningless when you already have population data.

\pause

\item If you have a sample that is non-random (biased), inference on the results will be unreliable.

\pause

\item The ultimate goal is to have independent observations.

\end{itemize}

\end{frame}
