\section*{Question 4. Build a Contingency Table}

Before comparing averages, investigate the categorical structure of the car data. Are manual and automatic cars spread evenly across cylinder groups, or are some combinations more common?

To do this, you'll need to create a contingency table. You saw contingency tables in Tutorial 2, but as a reminder: a contingency table shows counts for every combination of two categorical variables, so you can see at a glance which combinations are common and which are rare.

Use \texttt{mutate()} to create a readable transmission variable. Then produce a contingency table for \texttt{transmission} and \texttt{cyl}. You may use \texttt{table()}, \texttt{count()}, or the \texttt{group\_by()}/\texttt{summarize()}/\texttt{pivot\_wider()} approach from Tutorial 2.

\begin{lstlisting}[language=R]
cars2 <- cars %>%

# Option 1: table()
